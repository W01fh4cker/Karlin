`Vibe coding`实现的一个轻量级的多引擎多线程`Jar`/`Class`反编译的工具，主要解决有些`jar`包存在`FineFlower`引擎反编译正常、`Jadx`引擎反编译报错导致查看起来有点儿麻烦的问题。需要`JDK 17+`，通过如下命令启动：

```shell
java -jar karlin-0.0.1.jar
```
